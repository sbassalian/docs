Juno is the AI assistant built into the Growi dashboard. It uses the same tools as
the [MCP server](/ai/mcp-tools), so the answers match what Claude gives you through
a connector, and it already knows which organization you're looking at.

## What you can ask

- "Which creators drove the most revenue in the Spring campaign last month?"
- "Why was this creator paid $1,240 last cycle?"
- "Which sample applications are still waiting?"
- "Raise the Spring campaign's commission to 15%."

## How it differs from Claude over MCP

| | Juno | Claude over MCP |
| --- | --- | --- |
| Where | Inside the Growi dashboard | claude.ai, Claude Desktop, Claude Code, Cursor or any MCP client |
| Setup | None | Add a connector or an API key |
| Access | Your dashboard role | The role of the person the key belongs to |
| Changes | Previewed, then you confirm | Previewed, then you confirm |

Both only ever see your organization, and its child brands for a parent organization.
