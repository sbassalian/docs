## Deprecations

The old Home stats endpoints (`/stats/*` below) are deprecated and no longer appear
in this reference. They keep working exactly as before, so existing integrations
don't break, but don't build anything new on them. Use the replacements.

The deprecated endpoints take `MM/DD/YYYY` dates. Their replacements take ISO 8601
(`YYYY-MM-DD`), so change your date format when you switch.

Every response from a deprecated endpoint, errors included, carries:

| Header | Example | Meaning |
| --- | --- | --- |
| `Deprecation` | `@1793750400` | When it was deprecated, as a Unix timestamp ([RFC 9745](https://www.rfc-editor.org/rfc/rfc9745)) |
| `Link` | `<https://api.growi.io/api/public/v1/content/series>; rel="successor-version"` | The endpoint to use instead. Some list two |

| Deprecated | Use instead |
| --- | --- |
| `GET /stats/snapshots` | [`GET /content/series`](/api-reference/endpoint/content/series) |
| `GET /stats/content_24h_data`, `GET /stats/creators_24h` | [`GET /content/summary`](/api-reference/endpoint/content/summary) |
| `GET /stats/top_creators_by_engagement`, `GET /stats/top_creators_by_posts` | [`GET /content/top_creators`](/api-reference/endpoint/content/top-creators) |
| `GET /stats/top_connected_accounts_by_engagement` | [`GET /content/top_accounts`](/api-reference/endpoint/content/top-accounts) |
| `GET /stats/top_posts_by_views` | [`GET /content/top_posts`](/api-reference/endpoint/content/top-posts) |
| `GET /stats/content_platform_composition` | [`GET /content/top_platforms`](/api-reference/endpoint/content/top-platforms) |
| `GET /stats/user_contents` | [`GET /posts`](/api-reference/endpoint/content/posting-report) and [`GET /content/post_series`](/api-reference/endpoint/content/post-series) |
| `GET /stats/filters` | [`GET /content/filters`](/api-reference/endpoint/content/filters) |
| `GET /stats/tik_tok_shop_gmv_24h` | [`GET /tik_tok_shop/affiliate/summary`](/api-reference/endpoint/tik-tok-shop/affiliate-summary) and [`GET /tik_tok_shop/summary/weekly`](/api-reference/endpoint/tik-tok-shop/summary-weekly) |
| `GET /stats/tik_tok_shop_products` | [`GET /tik_tok_shop/products`](/api-reference/endpoint/get-tik-tok-shop-store-products) |
| `GET /stats/top_creators_by_gmv`, `GET /stats/top_earning_creators` | [`GET /stores/overview`](/api-reference/endpoint/stores/overview) and [`GET /shopify/stats`](/api-reference/endpoint/shopify/stats) |
| `GET /stats/payouts_24h`, `GET /stats/manual_campaign_progress` | [`GET /payouts/totals`](/api-reference/endpoint/payouts/payout-totals) |
| `GET /stats/creator_payouts` | [`GET /payouts`](/api-reference/endpoint/payouts/list-payouts) |
| `POST /stats/refresh_data` | Nothing. The new endpoints read live data |

`/stats/mark_credit_payout`, `/stats/transactions` and the ambassador endpoints
aren't deprecated.

## November 2026

<Update label="November 2026: deprecated endpoints hidden">
  **Changed**
  - The deprecated `/stats/*` endpoints are no longer listed in the API reference or search. They still work. See [deprecations](#deprecations) for what to use instead.
</Update>

<Update label="November 2026: spikes and breakouts">
  **New**
  - [Spike days](/api-reference/endpoint/content/spikes) and [what drove a day](/api-reference/endpoint/content/day-breakdown): days that jumped above normal and the posts behind them.
  - [Breakout posts](/api-reference/endpoint/content/breakout-posts): posts gaining far faster than their own pace right now.
  - [Content series by group](/api-reference/endpoint/content/series-by), [views per post](/api-reference/endpoint/content/per-post-series) and [post readings per day](/api-reference/endpoint/content/data-health).
  - MCP: `get_content_spikes`, `explain_day`, `list_breakout_posts`, and `group` on `get_content_series`.
</Update>

<Update label="November 2026">
  **New**
  - Content analytics: 14 `/content/*` endpoints with the numbers on your Home page, live on every call.
  - Sales and stores: `GET /stores/overview`, `GET /shopify/stats` (ambassador stats), `GET /shopify/store_creators` and its summary, and iOS and Android app analytics and creator funnels.
  - Payouts: `GET /payouts`, `GET /payouts/totals` and `GET /payouts/{uuid}`, the same rows as Finance → Payouts. Each payout has a `state` (`ready`, `updating` or `canceled`).
  - Meta ads performance: overview, over time, by creator and by creative.
  - All of them work with viewer keys, take ISO 8601 dates and accept `organization_id`.

  **Changed**
  - The old Home stats endpoints are deprecated. See the table above.
  - The API reference is grouped by product area. The old stats endpoints are no longer listed in it.
  - `GET /posts` (posting report) is documented.
  - `POST /stats/mark_credit_payout` now shows its parameters and responses.
</Update>
