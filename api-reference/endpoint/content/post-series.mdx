<Info>
  **Coming soon.** `GET /content/post_series` ships in the next API release.
  This page fills in with parameters, response fields and a playground when it does.
</Info>

<Tip>
  Replaces [`/stats/user_contents`](/api-reference/endpoint/get-user-contents), which is deprecated.
</Tip>

It works with full and read-only (viewer) API keys, counts toward the same
[rate limits](/api-reference/rate-limits) as every other endpoint, takes and returns
[ISO 8601 dates](/api-reference/conventions), and accepts `organization_id` to read
one of your [child brands](/api-reference/child-brands).
