---
title: "Get campaigns"
openapi: "GET /organizations/campaigns"
---

Retrieves every campaign and contract for your organization, with the deal details you need to show them outside Growi: image, brand, signup link, dates, payment details and tiers. For TikTok Shop retainer deals, `tiers` lists the pay for each GMV level.

## Request parameters

This endpoint does not require any specific parameters, but standard authentication is required.

| Parameter | Type | Description                                         | Required |
| --------- | ---- | --------------------------------------------------- | -------- |
| None      | -    | This endpoint does not accept additional parameters | -        |

## Request example

```bash
curl -X GET "https://api.growi.io/api/public/v1/organizations/campaigns" \
     -H "Authorization: Bearer YOUR_PUBLIC_API_KEY" \
     -H "Content-Type: application/json"
```

## Response fields

| Field | Type | Description |
| ----- | ---- | ----------- |
| `success` | Boolean | Indicates whether the request was successful |
| `campaigns` | Array | Array of campaign objects |
| `campaigns[].id` | Integer | Unique identifier for the campaign |
| `campaigns[].name` | String | Display name of the campaign |
| `campaigns[].campaign_type` | String | Type of campaign (Campaign, Contract, Ambassador Program) |
| `campaigns[].status` | String | Current status of the campaign (Active, Paused, Canceled, Completed, Archived, Void) |
| `campaigns[].description` | String or null | Campaign description, as HTML |
| `campaigns[].image_url` | String | Campaign share image if the brand uploaded one, otherwise the brand logo |
| `campaigns[].brand` | Object | `id`, `name` and `logo_url` of the brand that owns the campaign |
| `campaigns[].signup_url` | String or null | Page where creators apply. Null for contracts |
| `campaigns[].start_date` | String or null | Start date (YYYY-MM-DD) |
| `campaigns[].end_date` | String or null | End date (YYYY-MM-DD) |
| `campaigns[].platforms` | Array | Sales platforms the campaign tracks, such as `tik_tok_shop`, `shopify` or `amazon` |
| `campaigns[].currency` | String | Currency of every amount in `payment_details` and `tiers`, such as `usd` |
| `campaigns[].videos_per_cycle` | Integer | Videos a creator must post per cycle |
| `campaigns[].cycle_duration_days` | Integer | Cycle length in days. `0` means the deal does not repeat |
| `campaigns[].hide_payout_on_signup` | Boolean | True when the brand hides pay on its own Growi signup page. You may want to hide it too |
| `campaigns[].payment_details` | Array | Pay exactly as creators see it on the Growi signup page, one group per section |
| `campaigns[].payment_details[].title` | String | Section title, such as "Payment details" or "Retainer Tiers" |
| `campaigns[].payment_details[].type` | String | `standard` (base pay), `entry` (retainer paid by GMV level), `gmv` or `posts` (leaderboard prizes) |
| `campaigns[].payment_details[].items` | Array | Each item has a display `amount` and a `description` |
| `campaigns[].tiers` | Array | Active tiers, lowest level first. Money values are in currency units, not cents |
| `campaigns[].tiers[].type` | String | `standard`, or `entry` for retainer levels unlocked by the creator's GMV |
| `campaigns[].tiers[].level` | String | Tier name: bronze, silver, gold, platinum, diamond, elite, and so on |
| `campaigns[].tiers[].qualification_criteria` | String | Metric that unlocks the level, such as `gmv` |
| `campaigns[].tiers[].threshold` | Number | Amount of that metric needed to reach the level (GMV in currency units, posts as a count) |
| `campaigns[].tiers[].base_payment` | Number | Fixed pay at this level |
| `campaigns[].tiers[].commissions` | Array | Commission per sales platform: `platform`, `type` (`percentage` or `fixed`) and `value` |
| `campaigns[].tiers[].performance_payment` | Object or null | Pay per views or likes: `amount` paid per `per` `metric` |

## Use cases

- **Deal listings**: Show your pay-per-video and TikTok Shop deals on your own site or app, linking creators to `signup_url`
- **Campaign Filtering**: Use campaign IDs to filter data in other API endpoints
- **Campaign Management**: Retrieve available campaigns for management interfaces
- **Reporting**: Include campaign names, statuses and rates in reports and analytics dashboards
- **Status Monitoring**: Track campaign statuses across your organization

## Error responses

```json
{
  "error": "Not Authenticated"
}
```

Common error scenarios:

- **401 Unauthorized**: Invalid or missing Bearer token
- **403 Forbidden**: API key doesn't have permission to access campaigns
- **422 Unprocessable Entity**: Organization not found
- **500 Internal Server Error**: Server-side error occurred
