---
title: "Get content by platform"
openapi: "GET /stats/content_platform_composition"
description: "Retrieves a breakdown of content by platform within a specified date range."
---

<RequestExample>

```bash cURL
curl -X GET "https://api.growi.io/api/public/v1/stats/content_platform_composition?start_date=01/01/2023&end_date=01/31/2023" \
     -H "Authorization: Bearer YOUR_PUBLIC_API_KEY" \
     -H "Content-Type: application/json"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "content_platform_composition": {
      "tik_tok": 216,
      "instagram": 416,
      "twitter": 2,
      "youtube": 0,
      "unknown": 2
    }
  }
}
```

</ResponseExample>
