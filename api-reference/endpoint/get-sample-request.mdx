---
title: "Get sample request"
openapi: "GET /sample_requests/{id}"
---

Returns one sample request with the creator, product, variant and shipping address. The fields are the same as in [List sample requests](/api-reference/endpoint/list-sample-requests).

## Path parameters

| Parameter | Type | Description | Required |
| --- | --- | --- | --- |
| `id` | Integer | Sample request id, from the list endpoint or the `sample_request.id` of a webhook event | Yes |

## Request example

```bash
curl "https://api.growi.io/api/public/v1/sample_requests/812345" \
  -H "Authorization: Bearer YOUR_PUBLIC_API_KEY"
```

## Error responses

**404: not found for your organization**

```json
{ "error": "Sample request not found" }
```
