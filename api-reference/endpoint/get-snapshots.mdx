---
title: "Get snapshots"
openapi: "GET /stats/snapshots"
description: "Retrieves time-series data for content engagement metrics within a specified date range."
---

<RequestExample>

```bash cURL
curl -X GET "https://api.growi.io/api/public/v1/stats/snapshots?start_date=10/01/2025&end_date=11/14/2025" \
     -H "Authorization: Bearer YOUR_PUBLIC_API_KEY" \
     -H "Content-Type: application/json"
```

</RequestExample>
