---
title: "List sample requests"
openapi: "GET /sample_requests"
---

Lists free sample requests that you fulfill yourself, newest first. These are requests from creators on campaigns whose store isn't on Shopify. See [Free samples for custom stores](/essentials/custom-store-samples) for the full flow.

Requests on your child brands' campaigns are included.

## Query parameters

| Parameter | Type | Description | Required |
| --- | --- | --- | --- |
| `status` | String | Comma-separated: `pending`, `approved`, `shipped`, `delivered`, `rejected`, `cancelled` | No |
| `campaign_id` | Integer | Only requests on this campaign | No |
| `updated_since` | String | ISO-8601 timestamp. Only requests updated at or after this time, for incremental syncs | No |
| `page` | Integer | Page number (default `1`) | No |
| `per_page` | Integer | 1 to 100 (default `25`) | No |

## Request example

```bash
curl "https://api.growi.io/api/public/v1/sample_requests?status=approved" \
  -H "Authorization: Bearer YOUR_PUBLIC_API_KEY"
```

## Error responses

**401: missing or invalid API key**

```json
{ "error": "Not Authenticated" }
```

**422: invalid filter**

```json
{ "error": "updated_since must be an ISO-8601 timestamp" }
```
