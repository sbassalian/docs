---
title: "Create ads in bulk"
openapi: "POST /meta_ads/bulk"
---

Same payload and validation as the dashboard ad builder. Every row is checked and created on its own, so one bad row does not stop the others. Responds 207 with one result per row. Ads publish to Meta in the background: poll GET /meta_ads/publish_status.

Step 3 of the [Meta ads automation flow](/essentials/meta-ads-automation).

## How it works

1. Every row runs the same checks as the dashboard builder before anything is written. A row that fails comes back with `success: false` and an error `code`; the other rows still go ahead.
2. Each row that passes creates the ad (and a new campaign or ad set when you asked for one) in Growi with `state: queued`.
3. A background job publishes each ad to Meta: campaign, video, creative, ad set, ad. Poll [Get publish status](/api-reference/endpoint/meta-ads/get-publish-status).
4. Ads are created paused. With `launch_state: "active"` (or `auto_activate: true` on a partnership ad) the ad is turned on as soon as it publishes, and spend starts. Otherwise call [Launch an ad](/api-reference/endpoint/meta-ads/launch-ad) when you are ready.

The response is always `207` once the batch is accepted. Read `summary` and each row's `success`.

## Required fields

| Where | Fields |
| --- | --- |
| Row | `name`, `meta_ad_account_id`, `creative` |
| `creative` | `primary_text`, `headline`, `call_to_action`, `link_url`, plus the source row's `creative_source` keys |
| New `ad_set` (no `existing_meta_ad_set_id`) | `name`, `optimization_goal`, and exactly one of `daily_budget_cents` or `lifetime_budget_cents` |

Growi does not fill in your naming convention, default CTA, copy template text or UTM params for you. Read them from the [builder settings](/api-reference/endpoint/meta-ads/get-naming) endpoints and put the values in each row.

## Crediting the creator

The ad is credited to a creator, for sales and for ad spend commission, through the content and the link:

- A `social_post_id` attributed to a creator credits that creator's enrollment.
- Otherwise a `link_url` with the creator's Meta tag (`a=meta_<tag>`) credits the creator it belongs to. Get it from [Get creator Meta links](/api-reference/endpoint/meta-ads/list-creator-links).

Always use the creator's Meta link as `link_url` so purchases from the ad are attributed. See [How creators get credited](/essentials/meta-ads-automation#how-creators-get-credited-and-paid).

## Row error codes

| Code | Meaning |
| --- | --- |
| `PREFLIGHT_MISSING_FIELD` | A required field is missing. `details.missing` and `details.scope` say which. |
| `PREFLIGHT_NO_AD_ACCOUNT` | `meta_ad_account_id` is not one of your ad accounts |
| `PREFLIGHT_INVALID_OBJECTIVE` | Unknown `campaign.objective` |
| `PREFLIGHT_INVALID_OPTIMIZATION_GOAL` | Unknown `ad_set.optimization_goal` |
| `PREFLIGHT_NO_PIXEL` | A conversion goal with no pixel on the account. Install one or send `allow_optimization_fallback: true`. |
| `PREFLIGHT_NO_PAGE` | No active Facebook page on your organization |
| `PREFLIGHT_NO_INSTAGRAM_ACTOR` | No active Instagram account on your organization |
| `PREFLIGHT_INVALID_BUDGET` | Missing budget, both budgets, or not a positive integer |
| `PREFLIGHT_LINK_URL_INVALID` | `link_url` is not an http(s) URL |
| `PREFLIGHT_NO_VIDEO_SOURCE` | `creative` has no source key |
| `PREFLIGHT_SUBMISSION_NOT_FOUND` | Unknown `content_submission_version_id` |
| `PREFLIGHT_UNSUPPORTED_MEDIA_TYPE` | The submission is not a video or image |
| `PREFLIGHT_TTS_VIDEO_NOT_FOUND` | The TikTok Shop video has no sales in your shop |
| `PREFLIGHT_PARTNERSHIP_NOT_APPROVED` | The partnership request is missing, not approved, or the creator is not eligible |
| `PREFLIGHT_AUTO_ACTIVATE_REQUIRES_PARTNERSHIP` | `auto_activate: true` without `meta_partnership_ad_request_id` |
| `PREFLIGHT_CAMPAIGN_ARCHIVED` | The campaign is archived or deleted on Meta |
| `PREFLIGHT_AD_SET_FULL` | The ad set already holds Meta's maximum (50 ads, or 150 with Advantage+ audience on a sales campaign) |
| `BULK_ROW_EXCEPTION` | An unexpected error on this row. Other rows are not affected. |

<Warning>
Rows are checked one at a time against the ad set as it is when the request arrives. If 10 rows target an ad set that has 45 ads, all 10 can pass the check. Split rows across ad sets yourself using `ads_count` from [List ad sets](/api-reference/endpoint/meta-ads/list-ad-sets).
</Warning>

## Authentication

Needs a **full-access** API key. View-only keys get `403`. A key acts as the person who created it, with their current role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | ads is empty or has more than 50 rows |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |
