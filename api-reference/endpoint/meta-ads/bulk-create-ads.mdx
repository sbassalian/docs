---
title: "Create ads in bulk"
openapi: "POST /meta_ads/bulk"
---

Creates up to 50 Meta ads from creator content, into ad sets you already have. Every row runs the same checks as the dashboard ad builder and is created on its own, so one bad row does not stop the others. Responds `207` with one result per row.

Step 3 of the [Meta ads automation flow](/essentials/meta-ads-automation).

## How it works

1. Every row is checked before anything is written. A row that fails comes back with `success: false` and an error `code`; the other rows still go ahead.
2. Each row that passes creates the ad in Growi with `state: queued`, inside the ad set in `meta_ad_set_id`.
3. A background job publishes each ad to Meta (video, creative, ad). Poll [List ads](/api-reference/endpoint/meta-ads/list-ads) with `ids=`.
4. With `launch_state: "active"` the ad turns on as soon as it publishes, and spend starts. With `paused` (the default), call [Launch an ad](/api-reference/endpoint/meta-ads/launch-ad) when you are ready.

<Tip>
Send one bulk call of up to 50 rows with `launch_state: "active"` instead of creating ads one by one and launching each. With the default limit of 40 requests per hour per key, that keeps a daily job to a handful of calls.
</Tip>

## Row fields

| Field | Required | Notes |
| --- | --- | --- |
| `name` | Yes | Ad name. Build it from `settings.naming` in [options](/api-reference/endpoint/meta-ads/get-builder-options). |
| `meta_ad_account_id` | Yes | From options `ad_accounts` |
| `meta_ad_set_id` | Yes | An existing ad set of that ad account, from options `meta_ad_sets`. New ad sets and campaigns are made in the dashboard. |
| `launch_state` | No | `paused` (default) or `active` |
| `meta_partnership_ad_request_id` | No | From a [sources](/api-reference/endpoint/meta-ads/list-ad-sources) row. Runs the ad as the creator. |
| `copy_template_id` | No | Records which copy template the text came from |
| `creative.primary_text`, `creative.headline`, `creative.call_to_action`, `creative.link_url` | Yes | `call_to_action` must be a Meta CTA type, `link_url` an http(s) URL |
| `creative.description`, `creative.url_tags`, `creative.page_id`, `creative.identity_display` | No | `url_tags` takes your UTM params |
| `creative.require_instagram` | No | `false` runs the ad from the Facebook page when no Instagram identity is active |
| Source keys in `creative` | Yes | The sources row's `creative_source`: `social_post_id`, `tts_external_id` + `tts_username`, or `content_submission_version_id` |

Fields that are not listed here are ignored.

## Crediting the creator

Each ad records the creator enrollment it is credited to (`campaign_affiliate_id`), which drives sales attribution and ad spend commission:

- A `social_post_id` attributed to a creator credits that creator's enrollment.
- A `content_submission_version_id` credits the enrollment the submission came from.
- Otherwise a `link_url` with the creator's Meta tag (`a=meta_<tag>`) credits the creator it belongs to. Get it from `creator_links` in [options](/api-reference/endpoint/meta-ads/get-builder-options).

Always use the creator's Meta link as `link_url` so purchases from the ad are attributed. See [How creators get credited](/essentials/meta-ads-automation#how-creators-get-credited-and-paid).

## Row error codes

| Code | Meaning |
| --- | --- |
| `PREFLIGHT_MISSING_FIELD` | A required field is missing or invalid. `details.field` (or `details.missing`) says which: for example `meta_ad_set_id` is missing, not one of your ad sets, or belongs to another ad account, or `launch_state` is not `paused` or `active`. |
| `PREFLIGHT_NO_AD_ACCOUNT` | `meta_ad_account_id` is not one of your ad accounts |
| `PREFLIGHT_INVALID_CTA` | `creative.call_to_action` is not a Meta CTA type |
| `PREFLIGHT_NO_PAGE` | No active Facebook page on your organization |
| `PREFLIGHT_NO_INSTAGRAM_ACTOR` | No active Instagram identity. Send `creative.require_instagram: false` to run from the Facebook page only. |
| `PREFLIGHT_LINK_URL_INVALID` | `link_url` is not an http(s) URL |
| `PREFLIGHT_NO_VIDEO_SOURCE` | `creative` has no source key |
| `PREFLIGHT_SUBMISSION_NOT_FOUND` | Unknown `content_submission_version_id`, or a submission from another organization |
| `PREFLIGHT_UNSUPPORTED_MEDIA_TYPE` | The submission is not a video or image |
| `PREFLIGHT_TTS_VIDEO_NOT_FOUND` | The TikTok Shop video has no sales in your shop |
| `PREFLIGHT_PARTNERSHIP_NOT_APPROVED` | The partnership request is missing, not approved, or the creator is not eligible |
| `PREFLIGHT_NO_PIXEL` | The ad set optimizes for conversions and the ad account has no pixel |
| `PREFLIGHT_CAMPAIGN_ARCHIVED` | The ad set's campaign is archived or deleted on Meta |
| `PREFLIGHT_AD_SET_FULL` | The ad set already holds Meta's maximum (50 ads, or 150 with Advantage+ audience) |
| `BULK_ROW_EXCEPTION` | An unexpected error on this row. Other rows are not affected. |

<Note>
Rows run in order, and ads created by earlier rows in the same request count against the ad set. If 10 rows target an ad set that holds 45 of 50 ads, the first 5 are created and the last 5 fail with `PREFLIGHT_AD_SET_FULL`. Split rows across ad sets using `ads_count` and `max_ads` from options.
</Note>

## Authentication

Needs a **full-access** API key whose creator is an owner or admin. Legacy keys that are not tied to a person also work. View-only keys, and keys whose creator has the viewer role, get `403`. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key, or the key's user is not an owner or admin |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | `ads` is empty (`BULK_EMPTY`) or has more than 50 rows (`BULK_TOO_LARGE`) |
| `429` | Rate limited: 2 seconds between requests, and 40 requests per hour per key by default |
