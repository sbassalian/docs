---
title: "Generate Meta ad codes in bulk"
openapi: "POST /meta_ads/ad_codes/bulk_generate"
---

Owner or admin only. Queues ad code generation for Instagram posts attributed to your organization. Other ids are dropped. Check results later with GET /meta_ads/ad_codes.

## Authentication

Owner or admin only: the person who created the key needs the owner or admin role. View-only keys cannot call write endpoints. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key, or the key's user is not an owner or admin |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | No usable Instagram posts |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/meta_ads/ad_codes/bulk_generate" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "social_post_ids": [
         "instagram:3456789012345678901",
         "instagram:3456789012345678902"
       ]
     }'
```

</RequestExample>

<ResponseExample>

```json 200

  "success": true,

}
```

</ResponseExample>
