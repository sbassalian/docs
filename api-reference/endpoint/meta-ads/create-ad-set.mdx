---
title: "Create an ad set"
openapi: "POST /meta_ads/ad_sets"
---

Creates the ad set in Growi only. It is created on Meta when the first ad in it publishes. Use it when many ads in a bulk call should share one new ad set: create it here, then send its id as ad_set.existing_meta_ad_set_id.

## Body

| Field | Description |
| --- | --- |
| `name` | Ad set name |
| `meta_campaign_id` | Growi Meta campaign id from [List Meta campaigns](/api-reference/endpoint/meta-ads/list-campaigns) |
| `campaign_config` | Instead of `meta_campaign_id`: `{ "campaign_id": <Growi campaign id>, "objective": "OUTCOME_SALES", "name": "..." }` finds or creates a Meta campaign on the active ad account |
| `optimization.goal`, `optimization.billing_event` | Optimization goal and billing event (default `IMPRESSIONS`) |
| `budget.type`, `budget.amount_cents`, `budget.bid_strategy` | `daily` or `lifetime`, the amount in cents, and the bid strategy (default `LOWEST_COST_WITHOUT_CAP`) |
| `schedule.start_time`, `schedule.end_time` | ISO 8601 times |
| `pixel_id` | From [List pixels](/api-reference/endpoint/meta-ads/list-pixels) |
| `targeting`, `placements` | Same shape as `ad_set.targeting` and `ad_set.placements` on [Create ads in bulk](/api-reference/endpoint/meta-ads/bulk-create-ads) |

## Authentication

Needs a **full-access** API key. View-only keys get `403`. A key acts as the person who created it, with their current role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key |
| `404` | Meta campaign or Growi campaign not found, or organization_id is not a child brand of the key's organization |
| `422` | No active ad account, or the ad set is invalid |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/meta_ads/ad_sets" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "name": "Broad US 18-45",
       "meta_campaign_id": 41,
       "optimization": {
         "goal": "OFFSITE_CONVERSIONS",
         "billing_event": "IMPRESSIONS"
       },
       "budget": {
         "type": "daily",
         "amount_cents": 5000,
         "bid_strategy": "LOWEST_COST_WITHOUT_CAP"
       },
       "schedule": {
         "start_time": "2026-10-13T09:00:00-04:00"
       },
       "pixel_id": "998877665544332",
       "targeting": {
         "geo_locations": {
           "countries": [
             "US"
           ]
         },
         "age_min": 18,
         "age_max": 45
       },
       "placements": {
         "automatic": true
       }
     }'
```

</RequestExample>
