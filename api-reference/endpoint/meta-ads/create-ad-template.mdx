---
title: "Create an ad template"
openapi: "POST /meta_ads/templates"
---

budget_type is daily or lifetime.

## Authentication

Needs a **full-access** API key whose creator is an owner or admin. View-only keys, and keys whose creator has the viewer role, get `403`. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key, or the key's user is not an owner or admin |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | Invalid template |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/meta_ads/templates" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "name": "Daily creator launch",
       "description": "Sales, broad US",
       "campaign_objective": "OUTCOME_SALES",
       "budget_type": "daily",
       "budget_cents": 5000,
       "optimization_goal": "OFFSITE_CONVERSIONS",
       "targeting": {
         "geo_locations": {
           "countries": [
             "US"
           ]
         }
       },
       "copy_template_id": 3,
       "creatives_attributes": [
         {
           "name": "Default",
           "message": "The serum I reach for every morning.",
           "headline": "Glow in 7 days",
           "call_to_action": "SHOP_NOW",
           "link_url": "https://shop.example.com/products/glow-serum",
           "position": 0
         }
       ]
     }'
```

</RequestExample>
