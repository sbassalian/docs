---
title: "Create a copy template"
openapi: "POST /meta_ads/copy_templates"
---

label, primary_text and headline are required.

## Authentication

Needs a **full-access** API key. View-only keys get `403`. A key acts as the person who created it, with their current role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | Invalid template |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/meta_ads/copy_templates" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "label": "Morning routine",
       "primary_text": "The serum I reach for every morning.",
       "headline": "Glow in 7 days",
       "description": "Free shipping over $40",
       "link_description": null,
       "default": false
     }'
```

</RequestExample>
