---
title: "Create a UTM param"
openapi: "POST /meta_ads/utm_params"
---

key: letters, digits, _ and -, up to 40 characters, unique. value: up to 200 characters; Meta macros like `{{ad.id}}` are fine.

## Authentication

Needs a **full-access** API key. View-only keys get `403`. A key acts as the person who created it, with their current role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | Invalid or duplicate key |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/meta_ads/utm_params" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "key": "utm_campaign",
       "value": "creators_q4"
     }'
```

</RequestExample>

<ResponseExample>

```json 201
{
  "success": true,
  "data": {
    "id": 2,
    "key": "utm_campaign",
    "value": "creators_q4",
    "source": "user"
  }
}
```

</ResponseExample>
