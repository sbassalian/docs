---
title: "Generate a Meta ad code"
openapi: "POST /meta_ads/ad_codes/generate"
---

Owner or admin only. Uses the creator's approved partnership to get an ad code for the post. If the creator has not approved yet, the response says pending_approval and includes the approval link to share. Check success in the body: a failed generation still returns 200.

## Authentication

Owner or admin only: the person who created the key needs the owner or admin role. View-only keys cannot call write endpoints. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key, or the key's user is not an owner or admin |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | Post missing or not attributed to your organization |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/meta_ads/ad_codes/generate" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "social_post_id": "instagram:3456789012345678901"
     }'
```

</RequestExample>
