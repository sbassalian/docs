---
title: "Get Meta ad codes"
openapi: "GET /meta_ads/ad_codes"
---

Owner or admin only. The Instagram ad code status for each post you ask about. Posts not attributed to your organization are left out.

## Authentication

Owner or admin only: the person who created the key needs the owner or admin role. View-only keys cannot call write endpoints. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | The key's user is not an owner or admin |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | social_post_ids missing |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -g -X GET "https://api.growi.io/api/public/v1/meta_ads/ad_codes?social_post_ids[]=instagram:3456789012345678901" \
     -H "Authorization: Bearer YOUR_API_KEY"
```

</RequestExample>
