---
title: "List ads"
openapi: "GET /meta_ads"
---

The Ads tab: ads built in Growi plus external ads credited to a creator, with metrics for the date range. Deleted ads are hidden unless include_deleted=true.

Pass `group_by` to get folders (ad sets, Meta campaigns or Growi campaigns) with their ads inside, the way the Ads tab shows them. Folders are paginated, not ads.

Money fields in `stats` and `totals` are in cents of the ad account currency.

## Authentication

Any organization API key works, including view-only keys. A key acts as the person who created it, so that person needs the owner, admin or viewer role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `404` | organization_id is not a child brand of the key's organization |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X GET "https://api.growi.io/api/public/v1/meta_ads?status=failed&ids=9012,9013" \
     -H "Authorization: Bearer YOUR_API_KEY"
```

</RequestExample>
