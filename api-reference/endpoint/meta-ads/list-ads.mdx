---
title: "List ads"
openapi: "GET /meta_ads"
---

Lists your Meta ads with their publish status, newest first. Pass `ids` to poll the ads you created with [Create ads in bulk](/api-reference/endpoint/meta-ads/bulk-create-ads). Only ads built in Growi are listed unless `include_external=true`.

Step 4 of the [Meta ads automation flow](/essentials/meta-ads-automation).

## Polling publish status

Ads usually publish within a few minutes. Poll every few minutes, not every few seconds: each poll counts against the hourly limit.

| `state` | What to do |
| --- | --- |
| `queued`, `publishing` | Wait and poll again |
| `published` | On Meta and paused. [Launch it](/api-reference/endpoint/meta-ads/launch-ad) if you sent `launch_state: "paused"`. |
| `active` | Live and spending |
| `failed` | Read `error_message` and `last_step`, fix the content or settings, and create the ad again |

## Ad fields

| Field | Meaning |
| --- | --- |
| `id` | Growi ad id. Use it with get, launch and pause. |
| `meta_ad_id` | Meta's ad id, once the ad is on Meta |
| `state` | Growi publish state: `queued`, `publishing`, `published`, `active` or `failed` |
| `status` | Meta delivery status, such as `PAUSED`, `ACTIVE` or `DELETED` |
| `published` | `true` once the ad exists on Meta |
| `failed`, `error_message`, `last_step` | Why and where publishing or launching failed |
| `campaign_affiliate_id` | The creator enrollment credited for this ad's spend |
| `external` | `true` for ads imported from Ads Manager |

## Authentication

Any organization API key works, including view-only keys. A key acts as the person who created it, so that person needs the owner, admin or viewer role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | Unknown `state`, or more than 200 `ids` |
| `429` | Rate limited: 2 seconds between requests, and 40 requests per hour per key by default |
