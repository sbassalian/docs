---
title: "Get creator Meta links"
openapi: "GET /meta_ads/creator_links"
---

Each creator's Meta ad tracking link (it carries `a=meta_<tag>`). Use it as creative.link_url so the ad, its sales and its spend are credited to that creator. If an active enrollment has no Meta tag yet and the key can write (full access, owner or admin), this call creates one. With a view-only key or a viewer-role user it does not, and creators without a tag are left out. Creators with no active enrollment or no link base URL are also left out.

## Why this matters

Growi credits an ad to a creator through the destination URL. A Meta link carries `a=meta_<tag>`, the creator's Meta tag. Use it as `creative.link_url` on [Create ads in bulk](/api-reference/endpoint/meta-ads/bulk-create-ads) so purchases from the ad, and the ad's spend, are credited to that creator.

The link's own `utm_*` parameters are stripped. Put UTMs in `creative.url_tags` instead.

## Authentication

Any organization API key works, including view-only keys. A key acts as the person who created it, so that person needs the owner, admin or viewer role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `404` | organization_id is not a child brand of the key's organization |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -g -X GET "https://api.growi.io/api/public/v1/meta_ads/creator_links?creator_ids[]=2628998&creator_ids[]=2629001" \
     -H "Authorization: Bearer YOUR_API_KEY"
```

</RequestExample>
