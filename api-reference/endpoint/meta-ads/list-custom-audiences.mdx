---
title: "List custom audiences"
openapi: "GET /meta_ads/custom_audiences"
---

Custom audiences on the ad account (up to 200), read live from Meta. A new ad set can exclude them with targeting.excluded_custom_audiences.

## Authentication

Any organization API key works, including view-only keys. A key acts as the person who created it, so that person needs the owner, admin or viewer role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `404` | meta_ad_account_id not found, or organization_id is not a child brand of the key's organization |
| `422` | No connected ad account, or it needs reconnecting |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |
| `502` | Meta returned an error |
