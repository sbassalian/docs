---
title: "List partnership requests"
openapi: "GET /meta_ads/partnership_requests"
---

Owner or admin only. Approved requests let ads run as the creator: send the id as meta_partnership_ad_request_id. Without page or per_page every matching request is returned and meta is left out.

A creator approves a partnership request once. After that, ads can run with the creator's identity: send the approved request's `id` as `meta_partnership_ad_request_id` on [Create ads in bulk](/api-reference/endpoint/meta-ads/bulk-create-ads). [List ad sources](/api-reference/endpoint/meta-ads/list-ad-sources) already fills it in on each row when one exists.

Requests are sent from **Meta Ads → Partnerships** in the dashboard.

## Authentication

Owner or admin only: the person who created the key needs the owner or admin role. View-only keys cannot call write endpoints. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | The key's user is not an owner or admin |
| `404` | organization_id is not a child brand of the key's organization |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |
