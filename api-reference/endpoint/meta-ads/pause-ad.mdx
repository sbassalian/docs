---
title: "Pause an ad"
openapi: "POST /meta_ads/{id}/pause"
---

Sets the ad to PAUSED on Meta. If the ad has not reached Meta yet, only the Growi record changes and the publish keeps it paused.

## Authentication

Needs a **full-access** API key. View-only keys get `403`. A key acts as the person who created it, with their current role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | Meta rejected the pause, or no ad with this id in your organization |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/meta_ads/101/pause" \
     -H "Authorization: Bearer YOUR_API_KEY"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "meta_ad_id": 9012,
    "state": "published",
    "status": "PAUSED"
  }
}
```

</ResponseExample>
