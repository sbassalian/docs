---
title: "Pause an ad"
openapi: "POST /meta_ads/{id}/pause"
---

Sets the ad to `PAUSED` on Meta. If the ad has not reached Meta yet, only the Growi record changes and the publish keeps it paused.

## Authentication

Needs a **full-access** API key whose creator is an owner or admin. Legacy keys that are not tied to a person also work. View-only keys, and keys whose creator has the viewer role, get `403`. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key, or the key's user is not an owner or admin |
| `404` | No ad with this id in your organization, or organization_id is not a child brand of the key's organization |
| `422` | Meta rejected the pause (`PAUSE_FAILED`), or the ad was deleted (`AD_DELETED`) |
| `429` | Rate limited: 2 seconds between requests, and 40 requests per hour per key by default |

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/meta_ads/5012/pause" \
     -H "Authorization: Bearer YOUR_API_KEY"
```

</RequestExample>
