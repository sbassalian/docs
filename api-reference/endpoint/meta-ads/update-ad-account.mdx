---
title: "Turn ad account sync on or off"
openapi: "PATCH /meta_ads/ad_accounts/{id}"
---

The dashboard's auto-sync toggle. Ads and spend from every syncing account show up in Growi and count toward creator ad spend. PUT works too.

## Authentication

Needs a **full-access** API key. View-only keys get `403`. A key acts as the person who created it, with their current role. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | sync_enabled missing, or no ad account with this id |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X PATCH "https://api.growi.io/api/public/v1/meta_ads/ad_accounts/101" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "sync_enabled": true
     }'
```

</RequestExample>
