---
title: "Set naming convention"
openapi: "PUT /meta_ads/naming"
---

Tokens use single braces. `ad_name` and `campaign_name` allow `{creator}`, `{product}`, `{growiid}` and `{date}`. `ad_set_name` also allows `{account}`, `{campaign}` and `{objective}`.

## Authentication

Needs a **full-access** API key whose creator is an owner or admin. View-only keys, and keys whose creator has the viewer role, get `403`. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key, or the key's user is not an owner or admin |
| `404` | organization_id is not a child brand of the key's organization |
| `422` | Unknown token or bad braces |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X PUT "https://api.growi.io/api/public/v1/meta_ads/naming" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "ad_name": "{creator} | {product} | {date}",
       "ad_set_name": "{campaign} | {objective}",
       "campaign_name": "Creators | {date}"
     }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,

    "campaign_name": "Creators | {date}"

```

</ResponseExample>
