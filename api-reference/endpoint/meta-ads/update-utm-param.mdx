---
title: "Update a UTM param"
openapi: "PATCH /meta_ads/utm_params/{id}"
---

Auto params return 403. PUT works too.

## Authentication

Needs a **full-access** API key whose creator is an owner or admin. View-only keys, and keys whose creator has the viewer role, get `403`. See [Rate limits and authentication](/api-reference/introduction).

## Errors

| Status | When |
| ------ | ---- |
| `401` | Missing or invalid API key, or the person who created the key is no longer an owner, admin or viewer of the organization |
| `403` | View-only API key, or the key's user is not an owner or admin |
| `404` | UTM param not found, or organization_id is not a child brand of the key's organization |
| `422` | Invalid value |
| `429` | Rate limited: 2 seconds between requests, plus the hourly cap |

<RequestExample>

```bash cURL
curl -X PATCH "https://api.growi.io/api/public/v1/meta_ads/utm_params/101" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "value": "creators_q4_2026"
     }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "id": 2,
    "key": "utm_campaign",
    "value": "creators_q4",
    "source": "user"
  }
}
```

</ResponseExample>
