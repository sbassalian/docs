<Warning>
  **Deprecated.** This is one of the old Home stats endpoints. It still works, but new
  integrations should use the faster endpoints. No replacement needed. The new endpoints read live data, so there is nothing to refresh.
  Responses carry `Deprecation`, `Sunset` and `Link` headers. See [deprecations](/api-reference/changelog#deprecations).
</Warning>


Refreshes and re-syncs all creator social accounts data. This endpoint triggers a background job to update content snapshots and synchronize creator data across all connected platforms.

## Request example

```bash
curl -X POST "https://api.growi.io/api/public/v1/stats/refresh_data" \
     -H "Authorization: Bearer YOUR_PUBLIC_API_KEY" \
     -H "Content-Type: application/json"
```

## Response example

```json
{
  "success": true
}
```
