---
title: "Refresh data"
openapi: "POST /stats/refresh_data"
description: "Re-sync every creator's social account data."
---

Starts a background job that updates content snapshots and syncs creator data across all connected platforms.

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/stats/refresh_data" \
     -H "Authorization: Bearer YOUR_PUBLIC_API_KEY" \
     -H "Content-Type: application/json"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true
}
```

</ResponseExample>
