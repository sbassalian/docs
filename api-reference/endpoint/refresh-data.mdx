---
title: "Refresh data"
openapi: "POST /stats/refresh_data"
description: "Refreshes and re-syncs all creator social accounts data. This endpoint triggers a background job to update content snapshots and synchronize creator data across all connected platforms."
---

<RequestExample>

```bash cURL
curl -X POST "https://api.growi.io/api/public/v1/stats/refresh_data" \
     -H "Authorization: Bearer YOUR_PUBLIC_API_KEY" \
     -H "Content-Type: application/json"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true
}
```

</ResponseExample>
