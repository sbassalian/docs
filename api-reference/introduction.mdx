## Base URL

```text Base URL
https://api.growi.io/api/public/v1
```

## Authentication

Send your API key in the `Authorization` header on every request:

```text Header
Authorization: Bearer YOUR_API_KEY
```

Don't have a key yet? [Authentication](/authentication) shows where to create one.
