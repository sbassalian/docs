---
title: "Getting stats"
description: "Pull creator, content and GMV stats for your campaigns."
---

<Info>
  **Prerequisite** You need an API key. See [Authentication](/authentication) to create one.
</Info>

Every stats endpoint is a `GET` under `/stats`, authenticated with your API key as a Bearer token.

## Make your first request

```bash cURL
curl "https://api.growi.io/api/public/v1/stats/snapshots?start_date=2026-09-01&end_date=2026-09-24" \
  -H "Authorization: Bearer $GROWI_API_KEY"
```
