<Info>
  **Prerequisite** You need a Shopify store and admin access to your Growi dashboard.
</Info>

Two steps to track affiliate sales on a headless storefront and turn on automated discount codes.

## 1. Add tracking scripts to your root file

Put these two scripts in the `<head>` of your root HTML file:

```html index.html
<script src="https://shopify.growi.io/embed.js" defer="defer"></script>
<script src="https://shopify.growi.io/cookie-utils.js" defer="defer"></script>
```

This turns on affiliate sales tracking and, if you use them, automated discount codes.

## 2. Embed the signup form (optional)

Want visitors to sign up as ambassadors on your own site? Put this where the form should appear:

```html signup.html
<div data-growi-signup data-program="PROGRAM_ID"></div>
<script src="https://shopify.growi.io/embed-signup.js" defer></script>
```

### Getting your program ID

1. Open your Growi dashboard.
2. Go to **Shopify**, then **Ambassadors Program**, then **Setup**.
3. Click the clipboard icon next to your program to copy the ID.

<Frame>
  <img
    src="https://www.growi.io/images/shopify-embed-2.png"
    alt="Where to copy the Shopify program ID"
  />
</Frame>

Replace `PROGRAM_ID` in the code above with that ID.

## Example implementation

Both steps together:

```html index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Your Shopify Store</title>

  <!-- Growi Tracking Scripts -->
  <script src="https://shopify.growi.io/embed.js" defer="defer"></script>
  <script src="https://shopify.growi.io/cookie-utils.js" defer="defer"></script>
</head>
<body>
  <!-- Your page content -->

  <!-- Ambassador Signup Form (Optional) -->
  <div class="ambassador-signup-section">
    <h2>Become an Ambassador</h2>
    <div data-growi-signup data-program="your_program_id_here"></div>
    <script src="https://shopify.growi.io/embed-signup.js" defer></script>
  </div>
</body>
</html>
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Scripts aren't loading">
    Make sure both scripts are in the `<head>` of your root HTML file and the URLs are exact. Check your browser console for errors.
  </Accordion>
  <Accordion title="Affiliate tracking isn't working">
    Check that both tracking scripts load and that no JavaScript error stops them. They run after the page renders because of `defer`.
  </Accordion>
  <Accordion title="The signup form isn't showing">
    Check the program ID and that the signup script is on the page. You need admin access to the dashboard to copy the program ID.
  </Accordion>
  <Accordion title="Can't find the program ID">
    Go to **Shopify**, then **Ambassadors Program**, then **Setup** in the dashboard. If there's no program there, create an ambassador program first.
  </Accordion>
</AccordionGroup>
