<Info>
  **Prerequisite** You need a Stripe account and admin access to your Growi dashboard.
</Info>

Three steps to track affiliate sales that go through Stripe. There's also an [open-source example](https://github.com/Growi-Inc/stripe-integration-example) you can copy from.

## 1. Authenticate your Stripe account with Growi

In the dashboard, go to **Settings**, then **Integrations & Socials**, and click **Install Now** on the Stripe integration.

<Frame>
  <img
    src="/images/stripe1.png"
    alt="Stripe integration in Growi's Integrations & Socials settings"
  />
</Frame>

## 2. Add our tracking script

Add this script to your app:

```html index.html
<script
  async
  src="https://cdn.growi.io/growi.js"
  data-growi="{YOUR_PUBLIC_GROWI_ID}"
></script>
```

Your **Public Growi ID** is on the **Integrations & Socials** page in the dashboard.

<Frame>
  <img
    src="/images/stripe2.png"
    alt="Where to find the Public Growi ID"
  />
</Frame>

## 3. Send the affiliate code to Stripe

When someone lands on your site from a creator link, the script saves the code to `window.growi.affiliate_code`. Pass it to Stripe in `metadata` under the `growi_affiliate_code` key.

<CodeGroup>

```js Payment link
const paymentLink = await stripe.paymentLinks.create({
  line_items: [
    {
      price: "price_nj8h23ud",
      quantity: 1,
    },
  ],
  metadata: {
    growi_affiliate_code: window.growi.affiliate_code,
  },
});
```

```js Checkout session
const session = await stripe.checkout.sessions.create({
  line_items: [
    {
      price: "price_nj8h23ud",
      quantity: 1,
    },
  ],
  metadata: {
    growi_affiliate_code: window.growi.affiliate_code,
  },
  mode: "subscription",
});
```

```js Invoice
const invoice = await stripe.invoices.create({
  metadata: {
    growi_affiliate_code: window.growi.affiliate_code,
  },
});
```

</CodeGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Stripe integration isn't showing up">
    Make sure you have admin access and you're on **Settings**, then **Integrations & Socials** in the Growi dashboard.
  </Accordion>
  <Accordion title="The script isn't capturing the affiliate code">
    Check that the script is on every page a creator link can land on, and that the Public Growi ID is correct.
  </Accordion>
  <Accordion title="The affiliate code isn't reaching Stripe">
    Check that you pass `window.growi.affiliate_code` in the `metadata` of the Stripe object you create, under the `growi_affiliate_code` key.
  </Accordion>
</AccordionGroup>
